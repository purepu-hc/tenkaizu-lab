# 展開図ラボ

中学受験向けの展開図シミュレーターです。立体をえらび、その展開図をすべて一覧から選んで、3Dで折りたたんで確かめられます。

## 収録している立体

| 立体 | 展開図の数 |
| --- | --- |
| 立方体 | 11 |
| 直方体（4:3:2） | 54 |
| 三角柱 | 9 |
| 正四面体 | 2 |
| 四角すい | 8 |
| 正八面体 | 11 |
| 円柱 | 3例 |
| 円すい | 1例 |

多面体の展開図は、ブラウザ内ですべての切り開き方を調べ、重なるものを除き、回転・裏返しで同じになるものをまとめて求めています。

## 機能

- 折りぐあいをスライダーで自由に動かせる（0〜100%）
- 全部の面をいっしょに折る / 土台から順番に折る
- 面の形で色分け / 向かい合う面を同じ色に
- 立方体はサイコロの目（向かい合う面の和が7）を表示
- ななめ・真上・横の視点切り替え、ドラッグで回転、ピンチで拡大
- 辺や頂点をタップすると光るしるし（A・B…／①②…）。折ったあとも光ったまま。組み立てて重なる相手の辺・点も同じ色で表示（オフにするとクイズ用）
- スマホ対応

## 公開

`index.html` 1ファイルだけで動く静的サイトです。Vercel では Framework Preset を「Other」、Build Command を空欄にしてデプロイします。

three.js（r128）と Google Fonts は CDN から読み込みます。
